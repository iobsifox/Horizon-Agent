# Horizon Agent

## Summary

Horizon Agent is the cross-platform client and public distribution channel for Horizon Ticket System.

---

## Description

Horizon Ticket System combines a WordPress and WooCommerce support platform with Staffwind agent applications for Windows, macOS, Linux and Android. The public repository is used for installers, WordPress packages, checksums and machine-readable update metadata. Product source remains private.

Release `1.1.4` is the current public beta. It publishes Horizon Ticket System plugin `1.1.4` with the recognizable `horizon-agent/v1` REST namespace and a protected `hts/v1` compatibility alias. The Windows, macOS, Linux and Android application binaries remain unchanged at `1.1.1` and are published without commercial code-signing certificates.
